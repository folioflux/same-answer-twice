All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Library: `normalize`, `canonicalize` and `stableHash` for stable SHA-256 hashes of structured answers.
- Library: `diff` with numeric tolerances, ignored paths, unordered arrays and aligned array diffs.
- Library: `checkDeterminism`, `checkOutcomes`, `runRepeatedly` and `sameAnswerTwice`, with an optional expected answer.
- Library: `formatReport` with text, Markdown and JSON output.
- CLI: `same-answer-twice compare`, `run` and `hash`.
- Examples with synthetic data.
