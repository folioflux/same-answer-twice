# same-answer-twice

Does your AI agent give the same, row-cited answer to the same finance question twice? An open reproducibility and citation eval.

> **Status:** In development - not ready for use yet.

## What it will do

same-answer-twice will be an open eval for AI agents that answer finance questions over tabular data:

- Ask an agent the same finance question more than once over the same data and check whether the answers match.
- Check whether every number in an answer is backed by citations to the source rows, and whether those citations are correct.
- Publish the questions, data and scoring so anyone can run the eval and reproduce the results.
